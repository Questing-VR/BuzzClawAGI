# BuzzClawAGI 🐝🦑🧠

**The beautiful bastard child of:**
- **Buzz** (Block/Jack Dorsey) — Nostr-native human+agent workspace, crypto identities, ACP-agnostic
- **ZeroClaw** — Rust hardened runtime, sandboxes, tiny binary, security-first
- **OpenAGI** — Proactive daemon that watches, scores, self-improves, spawns specialists

They fucked. This is the baby.

## Vision
A self-sovereign, proactive, hardened agent that lives *inside* a Buzz workspace:
- Agents are full Nostr identities with scoped keys
- ZeroClaw-style WASM/Landlock sandboxes for every tool call
- OpenAGI-style continuous observation + Adaptive Scrutiny decision layer
- Auto-skill evolution + persistent specialist spawning
- Runs local-first, model-agnostic, with Buzz as the collaboration surface
